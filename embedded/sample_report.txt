Note: this target (QEMU lm3s6965evb, Cortex-M3) has NO hardware FPU,
so every add/sub/mul/div/compare on a float is a soft-float library
call -- that's why float-helper instructions dominate the count.
A real STM32F4-class flight computer (Cortex-M4F) has a hardware
single-precision FPU: the same C code, recompiled with -mfpu=fpv4-sp-d16

FADD/FMUL/FDIV/VCMP instructions -- this measurement is therefore a
deliberately conservative (worst-case, no-FPU) instruction count.
